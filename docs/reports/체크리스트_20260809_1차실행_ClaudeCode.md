**2차:** 1차 때 `⏸` 로 둔 25항목 중 10개는 장비가 아니라 **아직 이식하지 않은
코드** 때문이었다. scoring·sgf·snapshot·내장 AI 이식으로 해소.

**3차:** 남은 15항목 중 10개는 **화면·엔진 연결**이었다. 계가·힌트·무르기
버튼, 내장 AI 대국, KataGo 연결, 배우기 컨트롤러를 붙여 해소.

`GtpChannel` 인터페이스를 뽑아 **K4·K5 가 설치본 없이 검증**되게 바뀐 것이
3차의 가장 큰 변화다 — 장비 필요 항목이 41 → 38 로 준 이유가 이것이다.

**3차에서 나온 결함 4건**

1. **힌트 버튼이 영구 비활성** — `onPressed: false` 에 빈 콜백. 명령어로는
   되고 클릭으로는 안 되는 상태였다(두 입력 경로 동등성 위반).
2. **`undoMove` i18n 키 중복** — TS 객체 리터럴은 뒤 값이 조용히 이긴다.
   2차에서 넣은 중복 검사가 이걸 잡았고, 배우기 키에서 2건 더 잡았다.
3. **좌표 명령 `score`·`hint`·`undo` 가 빈 문자열 반환** — "화면이 처리한다"
   주석만 있고 화면에도 없었다. A13(명령이 낭독된다)의 조용한 실패.
4. **AI 응수 중 사람 착수가 막히지 않음** — 두 수가 겹치면 판이 어긋난다.

**4차:** 배우기·설정·계가 표시·SGF 대화상자를 붙여 `⏸` 를 1개로 줄였다.

**4차에서 나온 결함 5건 — 전부 "빌드도 되고 테스트도 통과하는" 것들이었다**

1. 🔴 **`main.dart` 가 1단계 스캐폴드 그대로였다.** 3단계에서 만든 대국 화면이
   6단계까지 앱에 연결되지 않았다. 289개 테스트가 통과하는데 앱을 켜면
   안내문만 나왔다. 화면별 테스트로는 절대 못 잡는다 → `app_boot_test.dart` 추가.
2. **`GoRules` 가 두 곳에 정의** — 설정과 엔진이 서로 다른 타입이라
   룰 설정이 `estimateScore` 에 도달할 수 없었다.
3. **테마 enum 에 한국어 라벨이 박혀 있었다** (`ContrastProfile` 등 4개).
   아무도 안 써서 테스트가 안 잡았지만, 처음 표시하는 화면에서 5개 언어 전부
   한국어가 나올 뻔했다.
4. **배우기 화면이 스크롤 안에서 판에 무한 높이를 줬다** — 레이아웃 예외.
5. **i18n 키 중복 6건** — 2차에서 넣은 검사가 전부 잡았다.

**1.0.0 은 전 항목 통과 시에만 태그한다.** 지금은 태그하지 않는다.

   `capturePoints` 로 교체(따냄 = 상대 그룹의 마지막 활로). 1분 미만으로.
2. **`capturePoints` 첫 판이 틀렸다** — 마지막 활로여도 패·슈퍼코면 못 둔다.

   테스트가 잡았다는 점이 중요하다.
3. **SGF 대문자 좌표가 조용히 패스가 됐다** — 아래 D 절.
