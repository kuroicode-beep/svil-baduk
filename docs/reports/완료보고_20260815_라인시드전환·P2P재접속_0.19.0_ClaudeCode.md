## 서체 전환

- Flutter 앱: `KyoboHandwriting2019`(시스템 의존 — 미설치 기기에서 조용히 맑은 고딕) → **LINESeedKR 번들**
- **Regular 만 탑재** — 이 앱은 합성 볼드 금지 규칙으로 위계를 크기·색으로만 만들어 다른 굵기를 안 쓴다 (Th·Bd 포함 시 +6.8MB, 실측으로 확인 후 제외 → 설치 58.8→52.3MB)
- 좌표·방 ID 의 Consolas 모노스페이스는 유지 — 0/O·1/I 혼동 방지 목적(접근성)이라 서체 통일 대상에서 제외
- 랜딩 페이지: `--font-ui` 에 선언만 있고 @font-face 가 없어 방문자에게 폴백이 보이던 것 — woff2 3굵기 + @font-face 배포 (200 확인)
- React 웹(src/)은 0.9.x 동결 원칙에 따라 미변경 (기본 서체가 여전히 교보손글씨 — 사용자 판단 필요 항목)
