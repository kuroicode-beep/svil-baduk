## 3. 발견하고 고친 결함

### 조용히 통과하던 것들 (테스트가 초록인데 틀린 것)

1. 🔴 **`main.dart` 가 1단계 스캐폴드 그대로였다.** 3단계에서 만든 대국 화면이
   6단계까지 앱에 연결되지 않았다. 테스트 289개가 통과하는데 앱을 켜면 안내문만
   나왔다. **화면별 테스트로는 원리적으로 못 잡는다** → `app_boot_test.dart` 추가.
2. **`GoRules` 가 두 곳에 정의** — 설정과 엔진이 서로 다른 타입이라 룰 설정이
   `estimateScore` 에 도달할 수 없었다.
3. **테마 enum 4개에 한국어 라벨이 박혀 있었다.** 아무도 안 써서 테스트가 안
   잡았지만, 처음 표시하는 화면에서 5개 언어 전부 한국어가 나왔을 것이다.
4. **좌표 명령 `score`·`hint`·`undo` 가 빈 문자열 반환** — "화면이 처리한다"
   주석만 있고 화면에도 없었다. 접근성 항목 A13 의 조용한 실패.
5. **힌트 버튼이 영구 비활성** (`onPressed: false` + 빈 콜백).

### 엔진·데이터

6. **내장 AI 가 O(n²)** — 수마다 상대의 전 합법수를 시뮬레이션. 1000판 테스트가
   10분 타임아웃 초과. `capturePoints` 로 교체(따냄 = 상대 그룹의 마지막 활로) →
   1분 미만. **첫 구현은 틀렸다** — 패·슈퍼코를 안 걸렀고, 추론이 아니라
   전수 시뮬레이션과의 **동치성 테스트가 잡았다.**
7. **SGF 대문자 좌표가 조용히 패스로 삼켜졌다.** 정규식만 고쳤더니 이번엔
   "빈 대국"으로 통과 — 같은 손상의 다른 얼굴이라 토큰 개수 대조로 막았다.
8. **배치 문제 슈퍼코 유실** — `initialBoard` 가 없어 재생이 빈 판에서 시작,
   사활 문제 배치가 통째로 사라졌다.
9. **Zobrist 시드 `0x5D8BADUK5EED`** — `U`·`K` 는 16진수가 아니다.
10. **P2P 재연결이 판을 초기화**, **착수 검증 부재** (프로토콜 2에서 수정).
11. **`flutter_webrtc` 한국어 로케일 빌드 실패** (C4819) → `/utf-8` 로 해결.
12. **i18n 키 중복 6건** — 2차에서 넣은 중복 검사가 전부 잡았다.

### 접근성

13. **반전 팔레트에서 흑돌 테두리 대비 1.14:1**, **표준 프로파일 테두리 3:1 미만**
    — 대비 테스트가 잡았다.
14. **`pointLabel` 수직 반전** — GTP 파서가 정확한 역함수여서 **왕복 테스트가
    완벽히 통과하는 동안 KataGo 는 거울 판에서 뒀다.** 그래서 좌표 변환은 왕복이
    아니라 **알려진 값**(19줄 좌상 화점 = D16)으로 못박는 테스트를 따로 뒀다.

### 내 실수 2건

- 실패하는 테스트를 커밋했다(`f035e09`) — 출력 꼬리만 보고 판단. `65a4eab` 에서 수정.
- 가드레일 정규식이 CRLF 에서 깨졌다(줄끝 앵커 + `\r`).

### 코드 잔여

- `src-tauri/` 삭제 (React 웹이 아직 Tauri 셸을 쓴다 — 7단계 종료 시)

### 기록해 둔 한계

`kill`/`live` 학습 목표는 **사활 판정기 없이 기계 검증이 불가능**하다. 계획서가 지적한
"실제로 아무것도 죽지 않는 문제 3개가 CI 를 통과한다"의 원인이 이것이고, 사활 판정기는
명시적으로 범위 밖이다. **영구히 사람 검토 대상**으로 테스트 주석에 남겼다.

계가는 **사석을 판정하지 못한다.** 오차 크기를 실제 국면으로 고정한 테스트가 있고
(76 vs 78), 설정 화면에 그 한계를 문장으로 적어 두었다.
