## 1. 난이도 디자인 — 내장 AI 개편 (`src/ai/builtin.ts`)

검수에서 발견한 문제:

- 종반에 AI가 **자기 눈을 메워 자멸**하고, 패스 개념이 없어 대국이 정상 종료되지 않음
- 단수 도망·양단수·자충 회피 같은 기본 개념이 전혀 없음
- 후보수 평가가 후보마다 전체 합법수를 재계산하는 O(n⁴) 구조 → 19줄에서 심한 지연

개선 내용:

- **진짜 눈 판정** 도입 — 자기 눈 메우기 원천 금지 (모든 레벨)
- 휴리스틱 확장: 따냄 / 단수 걸기(+양단수) / 단수 도망·이음 / 자충(스스로 단수) 감점 / 초반 3·4선 선호, 1선 지양
- **합리적 패스**: 상대가 패스했고 급한 수(따냄·구출)가 없으면 같이 패스 → 계가로 정상 종국
- 평가 경량화(전수 재탐색 제거) + 레벨별 노이즈로 실수 유도 (레벨이 낮을수록 평가가 부정확)
- 슈퍼코 검사 최적화: `legalMoves`가 해시 Set을 1회만 구성 (`src/engine/board.ts`)
- 회귀 테스트: 자가대국이 300수 내 정상 종국하는지 검증 (`src/ai/selfplay.test.ts`)

레벨 1~10 랜덤 비율·KataGo visits 곡선은 기존 튜닝(0.7.6) 유지 — 휴리스틱 개선으로
"랜덤이 아닐 때의 수"가 자연스러워져 레벨 간 체감 차이가 커졌습니다.

## 2. 레벨(학습) 디자인 (`src/learn/`)

- **트랙별 4번째 스테이지 추가** (+9문제, 총 37문제):
  - 기본 4 「단수 응용」: 양단수 / 단수 도망 / 큰 쪽 잡기
  - 포석 4 「벌림과 큰 곳」: 두 칸 벌림 / 침입 압박 / 큰 곳 찾기
  - 사활 4 「귀의 사활」: 곧은 석집 죽이기 / 곧은 석집 살기 / 꺾인 석집
  - 전 문제 합법성·따냄 성립을 테스트로 검증
- **학습 → 캐릭터 XP 연동**: 첫 클리어 +8 XP, 스테이지 완주 보너스 +25 XP, 레벨업 알림 표시
- **힌트 단계화**: 목표만 표시 → 「힌트 보기」 → 「정답 보기」 (기존엔 힌트가 항상 노출)
- 정답 시 해설(note)을 정답 메시지에 병기, 정답 후 「다음」 버튼 강조

## 3. UI / 기능

- **무르기(Takeback)**: AI 대국에서 내 마지막 수 + AI 응수를 함께 되돌림 (복기와 별개, 스냅샷도 갱신)
- **기권 2단계 확인**: 오클릭 방지 — 「기권」 → 「정말 기권할까요? / 기권 확정 / 취소」
- **차례 표시 버그 수정**: AI 차례에도 "내 차례"로 표시되던 패널 메타줄 → "흑/백 차례"로 정확히 표시
- **홈 화면**: 배우기 버튼에 전체 학습 진행률(n/37) 표시
- **i18n 정비**: 보드 착수 aria 라벨·집 표시(흑집/백집)·돌 라벨·힌트/정답 라벨·기권 확인·
  멀티 QR 안내 등 하드코딩 한국어 문구를 5개 언어(ko/en/ja/zh/vi) 사전으로 이동
  — 영어·일본어 등 사용자에게 한글이 노출되던 문제 해소
